# Contributing

Thanks for your interest in improving this project.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create a virtual environment.
4. Install the dependencies from `requirements.txt`.
5. Run the notebooks in order.
6. Test the Flask application locally.

## What You Can Contribute

Some useful improvements include:

- Better model evaluation
- Additional entity categories
- Improved training strategies
- Better error analysis
- UI improvements
- Documentation fixes
- New examples for the demo

## Pull Requests

Please keep pull requests focused on one change where possible.

Before opening a PR:

- Make sure the notebooks run without unnecessary errors.
- Test the Flask app.
- Keep the repository structure simple.
- Avoid adding preprocessing or utility modules unless the project requirements change.

## Code Style

Use readable Python, meaningful variable names and short explanations around important NLP steps.

## Questions

For project-related discussion, open a GitHub issue or pull request.
