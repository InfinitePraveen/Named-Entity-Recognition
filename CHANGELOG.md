# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-09-04

### Added
- CoNLL-2003 dataset exploration notebook.
- spaCy NER training notebook.
- NER evaluation notebook.
- Flask demonstration web app.
- Interactive entity highlighting in the web interface.
- GitHub and LinkedIn profile links.
- Project documentation and contribution guidelines.

### Notes
- The project focuses on PERSON, LOCATION and ORGANIZATION entities.
- The trained `ner_model/` directory is generated after running the training notebook and is not committed by default.
